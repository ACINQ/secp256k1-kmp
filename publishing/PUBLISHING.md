# Publishing secp256k1-kmp artifacts

## snapshots

Snapshots are published to the Sonatype snapshot repository (https://central.sonatype.com/repository/maven-snapshots/).

- Download `snapshot-{linux/macos/windows}.zip` generated by the `Publish snapshot` github action
- unzip them in the `publishing` directory
- run `secp256k1-kmp-snapshot-deploy.sh`

## releases

Releases are published to the Sonatype staging repository. If all items are valid they will be published to `maven central` repository.

- Download `release-{linux/macos/windows}.zip` generated by the `Publish release` github action (which is triggered every time you publish a github release)
- unzip them in the `publishing` directory
- run `secp256k1-kmp-staging-upload.shc create` to sign all artifacts
- run `secp256k1-kmp-staging-upload.shc upload` to upload all artifacts
- log into sonatype, close and publish your staging repository. Artifacts will be available on Maven Central within a few hours.
